Algorithmic Trading

Реализация проекта "Algorithmic Trading".

Обзор

Этот проект реализует набор алгоритмов численного анализа — интерполяции и аппроксимации — для анализа и прогнозирования таблично-заданных функций, в частности, исторических данных котировок акций. Он предоставляет графический интерфейс для визуализации результатов различных методов и сравнения их характеристик.

Функциональность

- Интерполяция:
  - Метод кубических сплайнов.
  - Интерполяционный многочлен Ньютона n-ой степени.
- Аппроксимация:
  - Метод наименьших квадратов (с возможностью задания весов точек).
- Визуализация:
  - Графический интерфейс (GUI) для отображения графиков.
  - Возможность отображения до 5 графиков одновременно на одном поле.
  - Отображение информации о графиках (цвет, исходный файл, метод, параметры).
  - Интерактивный расчет значений функций по заданным координатам.
- Исследование производительности:
  - Сравнение времени выполнения алгоритмов интерполяции в зависимости от количества точек.
- Работа с данными:
  - Загрузка данных из CSV-файлов (формат: дата, значение, [вес]).
  - Возможность экстраполяции (продления графика вперед по времени) при аппроксимации.

Сборка

Для сборки проекта используется утилита make. Файл Makefile настроен со стандартным набором целей для GNU-программ:

make или make all: Сборка исполняемого файла.
make install: Установка программы (в произвольный каталог, опционально).
make uninstall: Удаление установленной программы.
make clean: Удаление скомпилированных файлов и артефактов сборки.
make dist: Создание архива с исходным кодом проекта.
make dvi: Открыть Readme.
make clang: Проверка стиля на соотвествие Google.
make leak: Проверка утечек в тестах
make gcov: Покрытие тестов
make test: Запуск тестов.

Пример:
make all
